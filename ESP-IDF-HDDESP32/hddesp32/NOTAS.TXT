### **1. Eliminar Búsqueda BLE**
- Remover toda la funcionalidad de escaneo Bluetooth
- Los ESP32 ya estarán registrados en Firebase por otros medios (configuración manual, web, etc.)
- El usuario solo verá y gestionará ESP32s ya existentes en la base de datos

### **2. Nueva Funcionalidad: Gestión de ESP32s Asignados**
- Los clientes podrán ver sus ESP32s asignados
- Podrán crear/editar paneles y asignar ESP32s disponibles
- Configuración de relays por panel
- Gestión de ubicaciones

## **Nueva Arquitectura de Flujo**

### **Para Usuarios Normales:**
1. **Dashboard** → Ver paneles actuales + botón "Gestionar ESP32s"
2. **Gestión ESP32s** → Lista de ESP32s asignados al cliente
3. **Configurar Panel** → Crear/editar panel y asignar ESP32 disponible
4. **Personalizar Relays** → Configurar nombres y comportamiento de relays

### **Para Administradores:**
1. **Dashboard** → Ver todos los paneles + botón "Gestionar ESP32s"  
2. **Gestión ESP32s** → Ver todos los ESP32s, asignar a clientes
3. **Configurar Panel** → Crear panel para cualquier cliente
4. **Personalizar Relays** → Configurar relays de cualquier panel

## **Funcionalidades Nuevas**

### **Gestión de ESP32s:**
- Ver ESP32s asignados al cliente logueado
- Estado de cada ESP32 (Online/Offline)
- Asignar ESP32 disponible a nuevo panel
- Reasignar ESP32 entre paneles
- Ver información técnica (MAC, IP, etc.)

### **Configuración de Paneles:**
- Crear panel con nombre y ubicación
- Seleccionar ESP32 de lista disponible
- Editar información de panel existente

### **Personalización de Relays:**
- Cambiar nombres de relays por panel
- Habilitar/deshabilitar relays individuales
- Configurar si relay es controlable remotamente
- Establecer tipo de contacto (NO/NC)
