El programa completo que se ejecuta en el ESP32 consta de 6 archivos Python que trabajan en conjunto para realizar diversas tareas. A continuación, te explicaré detalladamente el proceso y funcionalidad de cada archivo y cómo se integran en el programa principal `main.py`.

1. `wifi_manager.py`:
   - Este archivo define la clase `WiFiManager` que se encarga de la conexión y gestión de la conexión WiFi del ESP32.
   - En el método `__init__`, se inicializa la interfaz de red `sta_if` y se activa.
   - El método `connect_wifi` intenta conectarse a la red WiFi especificada por `SSID` y `PASSWORD`. Si no se puede conectar dentro de un tiempo límite, reintenta la conexión después de un tiempo de espera.
   - El método `ensure_wifi_connected` verifica si el ESP32 está conectado a la red WiFi y, si no lo está, llama a `connect_wifi` para intentar reconectar.
   - El método `get_current_time` obtiene la fecha y hora actual del servicio web "World Time API" y la devuelve en un formato legible.

2. `mqtt_manager.py`:
   - Este archivo define la clase `MQTTManager` que se encarga de la conexión y gestión de la comunicación MQTT.
   - En el método `__init__`, se guarda una referencia al `WiFiManager` y se inicializan las variables de configuración del broker MQTT.
   - El método `ensure_client` se asegura de que el cliente MQTT esté conectado al broker. Si no está conectado, llama a `reinitialize_client` para reiniciar la conexión.
   - El método `reinitialize_client` crea una nueva instancia del cliente MQTT y se conecta al broker usando las credenciales especificadas.
   - El método `publish_event` publica un evento en un tema específico del broker MQTT. Si falla la publicación, el evento se agrega a una cola de mensajes pendientes.

3. `performance_monitor.py`:
   - Este archivo define la función `check_performance` que se utiliza para medir el rendimiento de una función específica.
   - Antes de ejecutar la función, se recolecta la basura y se mide la memoria libre.
   - Se registra el tiempo de inicio, se ejecuta la función con los argumentos proporcionados y se registra el tiempo de finalización.
   - Después de la ejecución, se vuelve a recolectar la basura y se mide la memoria libre.
   - Se calcula el tiempo de ejecución y se muestra junto con la cantidad de memoria utilizada.

4. `relay_manager.py`:
   - Este archivo define la clase `RelayManager` que se encarga de la gestión de los relés conectados al ESP32.
   - En el método `__init__`, se inicializan los diccionarios para almacenar los pines de los relés, los estados de los relés y los tiempos de último disparo.
   - El método `setup_relay` configura un pin específico como entrada con resistencia pull-up y lo asocia a una función de callback. También almacena el estado inicial del relé.
   - El método `debounce` se utiliza para evitar falsos disparos de los relés debido a rebotes. Solo se llama al callback si ha pasado un período de tiempo suficiente desde el último disparo y el estado del relé ha cambiado.

5. `watchdog_manager.py`:
   - Este archivo define la clase `WatchdogManager` que se encarga de la gestión del temporizador de vigilancia (watchdog timer) del ESP32.
   - En el método `__init__`, se configura el temporizador de vigilancia con un tiempo de espera especificado (por defecto, 120 segundos).
   - El método `feed` se utiliza para alimentar al temporizador de vigilancia, lo que reinicia el temporizador y evita que el sistema se reinicie.

6. `main.py`:
   - Este es el archivo principal que orquesta todas las funcionalidades del programa.
   - Se importan los módulos necesarios y se crean instancias de los diferentes managers: `WiFiManager`, `MQTTManager`, `RelayManager` y `WatchdogManager`.
   - La función `get_current_datetime` obtiene la fecha y hora actual utilizando el `WiFiManager`. Si han pasado más de 10 minutos desde la última actualización, se llama a `update_datetime` para obtener una nueva fecha y hora.
   - La función `relay_callback` se ejecuta cuando se dispara un relé. Verifica la conexión WiFi, obtiene la fecha y hora actual, y publica un mensaje MQTT con el nombre del relé y su estado.
   - En la función `main`, se establece la conexión WiFi y MQTT, y se configuran los relés con sus respectivos callbacks.
   - El bucle principal se ejecuta continuamente, alimentando al temporizador de vigilancia y generando informes de memoria cada minuto si está habilitado.

En resumen, el programa completo realiza las siguientes tareas:
1. Establece y mantiene una conexión WiFi estable.
2. Se conecta a un broker MQTT y publica eventos cuando se disparan los relés.
3. Configura y monitorea los relés conectados al ESP32, evitando falsos disparos.
4. Obtiene la fecha y hora actual de un servicio web y la almacena en caché.
5. Utiliza un temporizador de vigilancia para evitar que el sistema se bloquee.
6. Opcionalmente, genera informes de memoria para monitorear el uso de recursos.

Este programa permite al ESP32 interactuar con los relés, publicar eventos a través de MQTT y mantener una conexión estable, todo mientras se asegura de que el sistema funcione de manera confiable y eficiente.
